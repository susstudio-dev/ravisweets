# Plan 1 — Transact: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the Ravi Sweets storefront from a demo that writes `sim_` payment references to a store that collects real money through Razorpay, verified server-side, reconciled daily.

**Architecture:** Money becomes integer paise everywhere, enforced by a type rename that makes the compiler find every call site. The storefront gains a product read path so the database — not a bundled TypeScript array — is the pricing authority. Next.js moves to Vercel so Route Handlers can exist, then a create-order / verify / webhook trio handles payment with the webhook as the authoritative writer. The client never states a price.

**Tech Stack:** pnpm 9.15.9 · Node ≥20 · Next 15.0.2 (App Router) · React 18.3.1 · TypeScript 5.6.3 · Supabase (Postgres + RLS + Edge Functions) · `@supabase/supabase-js` 2.104.1 · Vitest 2.1.8 · Razorpay Orders API + Webhooks · Vercel

**Spec:** [`docs/superpowers/specs/2026-07-26-ravisweets-revenue-path-design.md`](../specs/2026-07-26-ravisweets-revenue-path-design.md)

## Global Constraints

- **All money is integer paise.** `Money.amountPaise: number`, always an integer. One conversion, at render only. Any non-integer is a bug and must throw, not round silently.
- **The client never sends a price.** Checkout requests carry `{ productId, variantId, quantity }` only. Prices, discounts and shipping are computed server-side from the database.
- **Razorpay only in v1.** No COD. Remove the COD option from the UI rather than leaving it disabled.
- **The webhook is authoritative.** `verify` is an optimistic UX path; both write through the same idempotent transition.
- **Idempotency key:** `UNIQUE (razorpay_payment_id)` on `orders`. Handlers must tolerate the same event three times.
- **Package manager is pnpm**, workspace protocol `workspace:*`. Never run `npm install` in this repo.
- **Existing behaviour to preserve:** `SUPABASE_CONFIGURED` graceful degradation — the site must still render when Supabase env vars are absent.
- **Commit style:** Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`), matching the existing 43-commit history.
- **Test commands:** `pnpm --filter @ravisweets/shared test` and `pnpm --filter @ravisweets/storefront test`.

## Scope note — read before starting

This plan is larger than the spec's original week 2–3 estimate because of §2.2: **the storefront has no product read path.** `supabase/products.ts` contains 18 write functions and zero reads, so admin edits are written and never read back. Server-side re-pricing is impossible until that is fixed, so Task 6 is a prerequisite, not an enhancement.

Tasks 1–3 are safe to run against the current deploy. Task 4 changes hosting. Tasks 5–12 build the payment path. Tasks 13–15 take it live.

```ts
import { REGIONS, type RegionCode } from './types/region';
import type { CurrencyCode } from './types/region';
import type { Money } from './types/product';

export const PAISE_PER_RUPEE = 100;

/**
 * Money in this codebase is ALWAYS integer paise. The two bugs in git history
 * — `catalogue prices were 100× too high` and `paise/rupee mismatch` — both came
 * from a `Money.amount` whose unit depended on where you read it. These helpers
 * make the unit explicit at every construction site and throw rather than round.
 */
export function assertPaise(amountPaise: number): void {
  if (!Number.isInteger(amountPaise)) {
    throw new RangeError(`money: expected integer paise, received ${amountPaise}`);
  }
}

export function rupeesToPaise(amountRupees: number): number {
  if (!Number.isFinite(amountRupees)) {
    throw new RangeError(`rupeesToPaise: expected a finite number, received ${amountRupees}`);
  }
  // Round away from zero at the half — Math.round(-0.5) is -0, which would
  // silently swallow a half-paise refund.
  const scaled = amountRupees * PAISE_PER_RUPEE;
  return scaled < 0 ? -Math.round(-scaled) : Math.round(scaled);
}

export function paiseToRupees(amountPaise: number): number {
  assertPaise(amountPaise);
  return amountPaise / PAISE_PER_RUPEE;
}

export function paise(amountPaise: number, currency: CurrencyCode = 'INR'): Money {
  assertPaise(amountPaise);
  return { amountPaise, currency };
}

export function rupees(amountRupees: number, currency: CurrencyCode = 'INR'): Money {
  return { amountPaise: rupeesToPaise(amountRupees), currency };
}

export function addMoney(a: Money, b: Money): Money {
  if (a.currency !== b.currency) {
    throw new TypeError(`addMoney: currency mismatch ${a.currency} vs ${b.currency}`);
  }
  assertPaise(a.amountPaise);
  assertPaise(b.amountPaise);
  return { amountPaise: a.amountPaise + b.amountPaise, currency: a.currency };
}

export function multiplyMoney(money: Money, quantity: number): Money {
  if (!Number.isInteger(quantity)) {
    throw new RangeError(`multiplyMoney: quantity must be an integer, received ${quantity}`);
  }
  assertPaise(money.amountPaise);
  return { amountPaise: money.amountPaise * quantity, currency: money.currency };
}

export function applyPercentOff(money: Money, percent: number): Money {
  if (!Number.isFinite(percent) || percent < 0 || percent > 100) {
    throw new RangeError(`applyPercentOff: percent must be 0..100, received ${percent}`);
  }
  assertPaise(money.amountPaise);
  const discount = Math.round((money.amountPaise * percent) / 100);
  return { amountPaise: money.amountPaise - discount, currency: money.currency };
}

export function formatMoney(money: Money, regionCode: RegionCode = 'in'): string {
  const region = REGIONS[regionCode];
  return new Intl.NumberFormat(region.locale, {
    style: 'currency',
    currency: money.currency,
    maximumFractionDigits: money.currency === 'INR' ? 0 : 2,
  }).format(paiseToRupees(money.amountPaise));
}
```

```markdown
# Migrations

Applied in lexical filename order.

## Known ambiguity: two `0002_` files

- `0002_content_reviews_festivals.sql`
- `0002_product_unit_mode.sql`

Both were authored against the `0001` schema and touch disjoint tables
(`reviews`/`festivals` vs `products.unit_mode`), so either order produces the
same result. Lexical sort puts `content` before `product`, which is the order
already applied in every existing environment.

**They are deliberately not renamed.** The Supabase CLI tracks applied
migrations by filename; renaming would make an applied migration look new and
re-run it.

## Rules for new migrations

1. Next free number is `0010`. Never reuse a number.
2. Every migration must be idempotent — `if not exists`, `create or replace`,
   and `drop policy if exists` before `create policy`. `SETUP_ALL.sql` is
   re-run against existing databases and must stay safe.
3. Money columns are **integer paise**, named `*_paise` for new columns.
   The pre-existing `variants.price_amount` and `products.sale_price` are
   already paise despite their names.
```

```ts
import 'server-only';
import { createClient, type SupabaseClient } from '@supabase/supabase-js';

/**
 * Service-role client. Bypasses RLS — every query made through it is fully
 * trusted, so it must never be imported into a client component. The
 * `server-only` import makes that a build error rather than a data leak.
 *
 * Distinct from lib/supabase/client.ts, which is the browser anon client and
 * returns null on the server by design.
 */
let cached: SupabaseClient | null = null;

export function getServiceClient(): SupabaseClient {
  if (cached) return cached;

  const url = process.env.NEXT_PUBLIC_SUPABASE_URL;
  const key = process.env.SUPABASE_SERVICE_ROLE_KEY;

  if (!url) throw new Error('getServiceClient: NEXT_PUBLIC_SUPABASE_URL is not set');
  if (!key) throw new Error('getServiceClient: SUPABASE_SERVICE_ROLE_KEY is not set');

  cached = createClient(url, key, {
    auth: { persistSession: false, autoRefreshToken: false },
  });
  return cached;
}
```

```sql
-- ─── 0010 — Real payments: Razorpay columns, event log, stock reservation ───
-- Idempotent per supabase/migrations/README.md.

-- 1. Payment columns on orders ------------------------------------------------
alter table public.orders
  add column if not exists razorpay_order_id   text,
  add column if not exists razorpay_payment_id text,
  add column if not exists amount_paise        int,
  add column if not exists payment_status      text not null default 'pending',
  add column if not exists paid_at             timestamptz,
  add column if not exists failure_reason      text;

comment on column public.orders.amount_paise is
  'Authoritative order total in integer paise, computed server-side. The legacy
   total/subtotal/shipping columns are display mirrors and must not be trusted.';

-- The idempotency key. A repeated webhook cannot create a second paid order.
create unique index if not exists uq_orders_razorpay_payment_id
  on public.orders (razorpay_payment_id)
  where razorpay_payment_id is not null;

create index if not exists idx_orders_razorpay_order_id
  on public.orders (razorpay_order_id)
  where razorpay_order_id is not null;

create index if not exists idx_orders_payment_status
  on public.orders (payment_status);

alter table public.orders
  drop constraint if exists orders_payment_status_check;
alter table public.orders
  add constraint orders_payment_status_check
  check (payment_status in ('pending', 'paid', 'failed', 'refunded'));

-- 2. Raw webhook log ----------------------------------------------------------
-- Every event Razorpay sends, verified or not. This is the audit trail and the
-- replay source when something goes wrong during a festival rush.
create table if not exists public.payment_events (
  id                bigserial primary key,
  razorpay_event_id text,
  event_type        text not null,
  razorpay_order_id text,
  razorpay_payment_id text,
  signature_valid   boolean not null,
  payload           jsonb not null,
  received_at       timestamptz not null default now(),
  processed_at      timestamptz,
  process_error     text
);

create unique index if not exists uq_payment_events_event_id
  on public.payment_events (razorpay_event_id)
  where razorpay_event_id is not null;

create index if not exists idx_payment_events_payment
  on public.payment_events (razorpay_payment_id);

-- 3. Stock reservation --------------------------------------------------------
create table if not exists public.stock_reservations (
  id          uuid primary key default gen_random_uuid(),
  order_id    text not null references public.orders(id) on delete cascade,
  variant_id  text not null references public.variants(id),
  quantity    int  not null check (quantity > 0),
  created_at  timestamptz not null default now(),
  released_at timestamptz
);

create index if not exists idx_stock_reservations_order
  on public.stock_reservations (order_id);

/**
 * Decrement stock for every line of an order, atomically. Raises if any line
 * would go negative, so an oversold festival SKU fails the payment rather than
 * silently promising sweets that do not exist.
 */
create or replace function public.reserve_stock(p_order_id text)
returns void
language plpgsql
security definer
set search_path = public
as $$
declare
  r record;
begin
  for r in
    select variant_id, quantity from public.stock_reservations
    where order_id = p_order_id and released_at is null
  loop
    update public.variants
       set stock_available = stock_available - r.quantity
     where id = r.variant_id
       and stock_available >= r.quantity;

    if not found then
      raise exception 'insufficient stock for variant %', r.variant_id
        using errcode = 'check_violation';
    end if;
  end loop;
end;
$$;

-- 4. RLS ----------------------------------------------------------------------
alter table public.payment_events enable row level security;
alter table public.stock_reservations enable row level security;

-- Neither table is customer-readable. Only the service role touches them, and
-- the service role bypasses RLS — so no permissive policy is created here.
drop policy if exists payment_events_no_client_access on public.payment_events;
drop policy if exists stock_reservations_no_client_access on public.stock_reservations;
```

```ts
import type { Money } from '../types/product';
import { addMoney, multiplyMoney, paise } from '../money';

/** Free shipping at ₹999 and above — matches the promo strip's default copy. */
export const FREE_SHIPPING_THRESHOLD_PAISE = 99_900;
export const FLAT_SHIPPING_PAISE = 7_900;

export interface QuoteLineInput {
  variantId: string;
  quantity: number;
}

/** Authoritative per-variant data, read from the database. Never from the client. */
export interface PricedVariant {
  variantId: string;
  productId: string;
  pricePaise: number;
  stockAvailable: number;
  onSale: boolean;
  salePrice: number | null;
  salePercentOff: number | null;
  saleEndsAt: string | null;
}

export interface CouponRule {
  code: string;
  kind: 'percent' | 'flat';
  /** Whole percent (1..100) for `percent`; paise for `flat`. */
  value: number;
  minSubtotalPaise: number;
  expiresAt: string | null;
}

export interface QuoteLine {
  variantId: string;
  productId: string;
  quantity: number;
  unitPrice: Money;
  lineTotal: Money;
}

export type QuoteFailure =
  | 'empty-cart'
  | 'unknown-variant'
  | 'invalid-quantity'
  | 'insufficient-stock'
  | 'coupon-expired'
  | 'coupon-min-subtotal'
  | 'coupon-unknown';

export type Quote =
  | {
      ok: true;
      lines: QuoteLine[];
      subtotal: Money;
      discount: Money;
      shipping: Money;
      total: Money;
      appliedCoupons: string[];
    }
  | { ok: false; reason: QuoteFailure; detail?: string };

export interface QuoteInput {
  lines: QuoteLineInput[];
  variants: PricedVariant[];
  coupons: CouponRule[];
  /** Injected so tests are deterministic. */
  now: number;
}

function effectiveUnitPaise(v: PricedVariant, now: number): number {
  const saleActive = v.onSale && (!v.saleEndsAt || Date.parse(v.saleEndsAt) > now);
  if (!saleActive) return v.pricePaise;
  if (typeof v.salePrice === 'number' && v.salePrice > 0) return v.salePrice;
  if (typeof v.salePercentOff === 'number' && v.salePercentOff > 0) {
    return v.pricePaise - Math.round((v.pricePaise * v.salePercentOff) / 100);
  }
  return v.pricePaise;
}

/**
 * The single source of truth for what a cart costs. Pure: every input is
 * explicit, so the whole matrix of sales, coupons and stock is unit-testable
 * without a database or a clock.
 */
export function quoteCart({ lines, variants, coupons, now }: QuoteInput): Quote {
  if (lines.length === 0) return { ok: false, reason: 'empty-cart' };

  const byId = new Map(variants.map((v) => [v.variantId, v]));
  const quoted: QuoteLine[] = [];

  for (const line of lines) {
    if (!Number.isInteger(line.quantity) || line.quantity <= 0) {
      return { ok: false, reason: 'invalid-quantity', detail: line.variantId };
    }
    const v = byId.get(line.variantId);
    if (!v) return { ok: false, reason: 'unknown-variant', detail: line.variantId };
    if (line.quantity > v.stockAvailable) {
      return { ok: false, reason: 'insufficient-stock', detail: line.variantId };
    }
    const unitPrice = paise(effectiveUnitPaise(v, now));
    quoted.push({
      variantId: v.variantId,
      productId: v.productId,
      quantity: line.quantity,
      unitPrice,
      lineTotal: multiplyMoney(unitPrice, line.quantity),
    });
  }

  const subtotal = quoted.reduce<Money>(
    (sum, l) => addMoney(sum, l.lineTotal),
    paise(0),
  );

  let discountPaise = 0;
  const applied: string[] = [];
  for (const c of coupons) {
    if (c.expiresAt && Date.parse(c.expiresAt) <= now) {
      return { ok: false, reason: 'coupon-expired', detail: c.code };
    }
    if (subtotal.amountPaise < c.minSubtotalPaise) {
      return { ok: false, reason: 'coupon-min-subtotal', detail: c.code };
    }
    discountPaise +=
      c.kind === 'percent'
        ? Math.round((subtotal.amountPaise * c.value) / 100)
        : c.value;
    applied.push(c.code);
  }

  // A stacked set of coupons must never make an order negative.
  discountPaise = Math.min(discountPaise, subtotal.amountPaise);

  const discounted = subtotal.amountPaise - discountPaise;
  const shippingPaise =
    subtotal.amountPaise >= FREE_SHIPPING_THRESHOLD_PAISE ? 0 : FLAT_SHIPPING_PAISE;

  return {
    ok: true,
    lines: quoted,
    subtotal,
    discount: paise(discountPaise),
    shipping: paise(shippingPaise),
    total: paise(discounted + shippingPaise),
    appliedCoupons: applied,
  };
}
```

```ts
import 'server-only';
import { createHmac, timingSafeEqual } from 'node:crypto';

const API_BASE = 'https://api.razorpay.com/v1';

function requireEnv(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`razorpay: ${name} is not set`);
  return value;
}

/** Constant-time compare that tolerates malformed input instead of throwing. */
function safeEqualHex(a: string, b: string): boolean {
  if (typeof a !== 'string' || typeof b !== 'string') return false;
  if (a.length !== b.length || a.length === 0) return false;
  try {
    return timingSafeEqual(Buffer.from(a, 'hex'), Buffer.from(b, 'hex'));
  } catch {
    return false;
  }
}

export interface CreateOrderInput {
  amountPaise: number;
  receipt: string;
  notes?: Record<string, string>;
}

export interface RazorpayOrder {
  id: string;
  amount: number;
  currency: string;
  status: string;
}

/**
 * Creates the Razorpay order. `amount` is paise — the same unit this codebase
 * uses everywhere, which is why no conversion happens here.
 */
export async function createRazorpayOrder({
  amountPaise,
  receipt,
  notes,
}: CreateOrderInput): Promise<RazorpayOrder> {
  if (!Number.isInteger(amountPaise) || amountPaise <= 0) {
    throw new RangeError(`createRazorpayOrder: amountPaise must be a positive integer, got ${amountPaise}`);
  }
  const keyId = requireEnv('RAZORPAY_KEY_ID');
  const keySecret = requireEnv('RAZORPAY_KEY_SECRET');
  const auth = Buffer.from(`${keyId}:${keySecret}`).toString('base64');

  const res = await fetch(`${API_BASE}/orders`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Basic ${auth}` },
    body: JSON.stringify({ amount: amountPaise, currency: 'INR', receipt, notes: notes ?? {} }),
  });

  if (!res.ok) {
    throw new Error(`createRazorpayOrder: Razorpay returned ${res.status} ${await res.text()}`);
  }
  return (await res.json()) as RazorpayOrder;
}

export interface VerifyCheckoutInput {
  orderId: string;
  paymentId: string;
  signature: string;
  /** Injectable for tests; defaults to the configured key secret. */
  secret?: string;
}

export function verifyCheckoutSignature({
  orderId,
  paymentId,
  signature,
  secret,
}: VerifyCheckoutInput): boolean {
  const key = secret ?? requireEnv('RAZORPAY_KEY_SECRET');
  const expected = createHmac('sha256', key).update(`${orderId}|${paymentId}`).digest('hex');
  return safeEqualHex(expected, signature);
}

export function verifyWebhookSignature(
  rawBody: string,
  headerSignature: string | null,
  secret?: string,
): boolean {
  if (!headerSignature) return false;
  const key = secret ?? requireEnv('RAZORPAY_WEBHOOK_SECRET');
  const expected = createHmac('sha256', key).update(rawBody).digest('hex');
  return safeEqualHex(expected, headerSignature);
}
```

```ts
/**
 * Human-facing order number: RS-YYMMDD-XXXX. Customers read this over the phone,
 * so it avoids characters that sound alike (0/O, 1/I).
 */
const ALPHABET = '23456789ABCDEFGHJKLMNPQRSTUVWXYZ';

export function generateOrderNumber(now: Date, random: () => number = Math.random): string {
  const yy = String(now.getUTCFullYear()).slice(2);
  const mm = String(now.getUTCMonth() + 1).padStart(2, '0');
  const dd = String(now.getUTCDate()).padStart(2, '0');
  let suffix = '';
  for (let i = 0; i < 4; i++) {
    suffix += ALPHABET[Math.floor(random() * ALPHABET.length)];
  }
  return `RS-${yy}${mm}${dd}-${suffix}`;
}
```

```ts
import { getVariantPrices } from '@/lib/supabase/products-read';
import { createRazorpayOrder } from '@/lib/payments/razorpay';
import { generateOrderNumber } from '@/lib/payments/order-number';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

interface RequestBody {
  lines: { variantId: string; quantity: number }[];
  address: Record<string, string>;
  couponCodes?: string[];
}

/**
 * The client sends variant ids, quantities and an address. It does NOT send
 * prices — everything monetary is recomputed here from the database, which is
 * what makes a tampered cart unprofitable.
 */
export async function POST(request: Request) {
  let body: RequestBody;
  try {
    body = (await request.json()) as RequestBody;
  } catch {
    return NextResponse.json({ error: 'invalid-json' }, { status: 400 });
  }

  if (!Array.isArray(body.lines) || body.lines.length === 0) {
    return NextResponse.json({ error: 'empty-cart' }, { status: 400 });
  }
  if (body.lines.length > 50) {
    return NextResponse.json({ error: 'too-many-lines' }, { status: 400 });
  }

  const supa = getServiceClient();

  // 1. Authoritative prices + stock, straight from the DB.
  const variantIds = body.lines.map((l) => l.variantId);
  const variants = await getVariantPrices(variantIds);

  // 2. Authoritative coupon rules. Client-supplied codes are looked up, never trusted.
  let coupons: CouponRule[] = [];
  const codes = (body.couponCodes ?? []).map((c) => c.trim().toUpperCase()).filter(Boolean);
  if (codes.length > 0) {
    const { data, error } = await supa
      .from('coupons')
      .select('code, kind, value, min_subtotal, expires_at, active')
      .in('code', codes);
    if (error) return NextResponse.json({ error: 'coupon-lookup-failed' }, { status: 500 });

    const rows = (data ?? []) as Array<{
      code: string; kind: 'percent' | 'flat'; value: number;
      min_subtotal: number | null; expires_at: string | null; active: boolean;
    }>;
    if (rows.length !== codes.length || rows.some((r) => !r.active)) {
      return NextResponse.json({ error: 'coupon-unknown' }, { status: 400 });
    }
    coupons = rows.map((r) => ({
      code: r.code,
      kind: r.kind,
      value: r.value,
      minSubtotalPaise: r.min_subtotal ?? 0,
      expiresAt: r.expires_at,
    }));
  }

  // 3. Price it.
  const quote = quoteCart({ lines: body.lines, variants, coupons, now: Date.now() });
  if (!quote.ok) {
    return NextResponse.json({ error: quote.reason, detail: quote.detail }, { status: 400 });
  }

  // 4. Persist as pending_payment BEFORE talking to Razorpay, so a payment can
  //    never exist against an order we have no record of.
  const orderId = crypto.randomUUID();
  const number = generateOrderNumber(new Date());

  const { error: insertError } = await supa.from('orders').insert({
    id: orderId,
    number,
    status: 'placed',
    payment_status: 'pending',
    address_snapshot: body.address,
    payment: { method: 'razorpay', reference: null },
    lines: quote.lines,
    subtotal: quote.subtotal.amountPaise,
    shipping: quote.shipping.amountPaise,
    discount: quote.discount.amountPaise,
    total: quote.total.amountPaise,
    amount_paise: quote.total.amountPaise,
    currency: 'INR',
    coupon_code: quote.appliedCoupons[0] ?? null,
  });
  if (insertError) {
    return NextResponse.json({ error: 'order-insert-failed' }, { status: 500 });
  }

  // 5. Reserve stock intent. reserve_stock() decrements on payment.captured.
  const reservations = quote.lines.map((l) => ({
    order_id: orderId,
    variant_id: l.variantId,
    quantity: l.quantity,
  }));
  await supa.from('stock_reservations').insert(reservations);

  // 6. Create the Razorpay order.
  let rpOrder;
  try {
    rpOrder = await createRazorpayOrder({
      amountPaise: quote.total.amountPaise,
      receipt: number,
      notes: { orderId, number },
    });
  } catch (err) {
    await supa
      .from('orders')
      .update({ payment_status: 'failed', failure_reason: String(err) })
      .eq('id', orderId);
    return NextResponse.json({ error: 'razorpay-unavailable' }, { status: 502 });
  }

  await supa.from('orders').update({ razorpay_order_id: rpOrder.id }).eq('id', orderId);

  return NextResponse.json({
    orderId,
    number,
    razorpayOrderId: rpOrder.id,
    amountPaise: quote.total.amountPaise,
    keyId: process.env.NEXT_PUBLIC_RAZORPAY_KEY_ID,
  });
}
```

```ts
import 'server-only';
import { getServiceClient } from '@/lib/supabase/server';

export type MarkPaidResult =
  | { ok: true; alreadyPaid: boolean }
  | { ok: false; reason: 'order-not-found' | 'amount-mismatch' | 'db-error'; detail?: string };

/**
 * The ONLY place an order becomes paid. Both /verify (optimistic, user-facing)
 * and the webhook (authoritative) call this, so a customer who closes the tab
 * mid-UPI and a customer who waits both end in exactly the same state.
 *
 * Idempotency rests on the unique index uq_orders_razorpay_payment_id from
 * migration 0010: a repeat call for the same payment is a no-op, not a second
 * stock decrement.
 */
export async function markOrderPaid(input: {
  orderId: string;
  razorpayPaymentId: string;
  expectedAmountPaise?: number;
}): Promise<MarkPaidResult> {
  const supa = getServiceClient();

  const { data: order, error: readError } = await supa
    .from('orders')
    .select('id, payment_status, amount_paise, razorpay_payment_id')
    .eq('id', input.orderId)
    .maybeSingle();

  if (readError) return { ok: false, reason: 'db-error', detail: readError.message };
  if (!order) return { ok: false, reason: 'order-not-found' };

  const row = order as {
    id: string;
    payment_status: string;
    amount_paise: number;
    razorpay_payment_id: string | null;
  };

  if (
    typeof input.expectedAmountPaise === 'number' &&
    input.expectedAmountPaise !== row.amount_paise
  ) {
    // Razorpay captured a different amount than we recorded. Never mark paid —
    // this is the signal that something is wrong upstream.
    return { ok: false, reason: 'amount-mismatch', detail: `${input.expectedAmountPaise} vs ${row.amount_paise}` };
  }

  if (row.payment_status === 'paid' && row.razorpay_payment_id === input.razorpayPaymentId) {
    return { ok: true, alreadyPaid: true };
  }

  const { error: updateError } = await supa
    .from('orders')
    .update({
      payment_status: 'paid',
      razorpay_payment_id: input.razorpayPaymentId,
      paid_at: new Date().toISOString(),
      payment: { method: 'razorpay', reference: input.razorpayPaymentId },
    })
    .eq('id', input.orderId)
    .neq('payment_status', 'paid');

  if (updateError) {
    // A concurrent writer won the race and set the same payment id — that is
    // success, not failure.
    if (updateError.message.includes('uq_orders_razorpay_payment_id')) {
      return { ok: true, alreadyPaid: true };
    }
    return { ok: false, reason: 'db-error', detail: updateError.message };
  }

  const { error: stockError } = await supa.rpc('reserve_stock', { p_order_id: input.orderId });
  if (stockError) {
    // Stock could not be decremented but the money is real. Flag loudly for the
    // ops queue rather than reversing a captured payment automatically.
    await supa
      .from('orders')
      .update({ failure_reason: `stock: ${stockError.message}` })
      .eq('id', input.orderId);
  }

  return { ok: true, alreadyPaid: false };
}
```

```ts
 * Optimistic confirmation so the customer sees a receipt immediately. The
 * webhook is authoritative — if this route never runs (tab closed mid-UPI),
```

```ts
import { NextResponse } from 'next/server';
import { verifyWebhookSignature } from '@/lib/payments/razorpay';
import { markOrderPaid } from '@/lib/payments/mark-paid';
import { getServiceClient } from '@/lib/supabase/server';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

interface RazorpayEvent {
  event: string;
  payload?: {
    payment?: {
      entity?: {
        id?: string;
        order_id?: string;
        amount?: number;
        error_description?: string;
        notes?: Record<string, string>;
      };
    };
    refund?: { entity?: { payment_id?: string } };
  };
}

/**
 * Authoritative payment state. Razorpay retries on non-2xx, so this must be
 * idempotent and must return 200 for anything it has durably recorded —
 * including events it chooses not to act on.
 */
export async function POST(request: Request) {
  // Raw body, byte for byte — re-serialising JSON would break the HMAC.
  const raw = await request.text();
  const signature = request.headers.get('x-razorpay-signature');
  const valid = verifyWebhookSignature(raw, signature);

  let event: RazorpayEvent;
  try {
    event = JSON.parse(raw) as RazorpayEvent;
  } catch {
    return NextResponse.json({ error: 'invalid-json' }, { status: 400 });
  }

  const supa = getServiceClient();
  const entity = event.payload?.payment?.entity;

  // Log every event, valid or not. An attacker probing the endpoint is
  // something worth seeing in the audit trail.
  const { data: logged } = await supa
    .from('payment_events')
    .insert({
      razorpay_event_id: request.headers.get('x-razorpay-event-id'),
      event_type: event.event ?? 'unknown',
      razorpay_order_id: entity?.order_id ?? null,
      razorpay_payment_id: entity?.id ?? null,
      signature_valid: valid,
      payload: event as unknown as Record<string, unknown>,
    })
    .select('id')
    .maybeSingle();

  if (!valid) {
    return NextResponse.json({ error: 'invalid-signature' }, { status: 400 });
  }

  const eventRowId = (logged as { id: number } | null)?.id ?? null;
  const finish = async (error?: string) => {
    if (eventRowId !== null) {
      await supa
        .from('payment_events')
        .update({ processed_at: new Date().toISOString(), process_error: error ?? null })
        .eq('id', eventRowId);
    }
  };

  const orderId = entity?.notes?.orderId;

  switch (event.event) {
    case 'payment.captured': {
      if (!orderId || !entity?.id) {
        await finish('missing orderId in notes');
        return NextResponse.json({ ok: true, skipped: 'missing-order-ref' });
      }
      const result = await markOrderPaid({
        orderId,
        razorpayPaymentId: entity.id,
        expectedAmountPaise: entity.amount,
      });
      await finish(result.ok ? undefined : `${result.reason}: ${result.detail ?? ''}`);
      // Still 200 — the event is recorded. Retrying would not change the outcome.
      return NextResponse.json({ ok: true, handled: 'payment.captured' });
    }

    case 'payment.failed': {
      if (orderId) {
        await supa
          .from('orders')
          .update({
            payment_status: 'failed',
            failure_reason: entity?.error_description ?? 'unknown',
          })
          .eq('id', orderId)
          .neq('payment_status', 'paid');   // never downgrade a paid order
      }
      await finish();
      return NextResponse.json({ ok: true, handled: 'payment.failed' });
    }

    case 'refund.processed': {
      const paymentId = event.payload?.refund?.entity?.payment_id;
      if (paymentId) {
        await supa
          .from('orders')
          .update({ payment_status: 'refunded' })
          .eq('razorpay_payment_id', paymentId);
      }
      await finish();
      return NextResponse.json({ ok: true, handled: 'refund.processed' });
    }

    default:
      await finish();
      return NextResponse.json({ ok: true, ignored: event.event });
  }
}
```

```js
 * end. Exits non-zero on any discrepancy so CI marks the run failed.
 *
 * Usage: node scripts/reconcile.mjs [YYYY-MM-DD]
 */
import { createClient } from '@supabase/supabase-js';

const day = process.argv[2] ?? new Date(Date.now() - 86_400_000).toISOString().slice(0, 10);
const from = Math.floor(Date.parse(`${day}T00:00:00Z`) / 1000);
const to = from + 86_400;

const { NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET } = process.env;
for (const [k, v] of Object.entries({ NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET })) {
  if (!v) { console.error(`Missing env: ${k}`); process.exit(2); }
}

const auth = Buffer.from(`${RAZORPAY_KEY_ID}:${RAZORPAY_KEY_SECRET}`).toString('base64');
const res = await fetch(`https://api.razorpay.com/v1/payments?from=${from}&to=${to}&count=100`, {
  headers: { Authorization: `Basic ${auth}` },
});
if (!res.ok) { console.error(`Razorpay ${res.status}: ${await res.text()}`); process.exit(2); }

const captured = (await res.json()).items.filter((p) => p.status === 'captured');

const supa = createClient(NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, { auth: { persistSession: false } });
const { data: orders, error } = await supa
  .from('orders')
  .select('id, number, razorpay_payment_id, amount_paise, payment_status')
  .gte('paid_at', `${day}T00:00:00Z`)
  .lt('paid_at', `${day}T23:59:59.999Z`)
  .eq('payment_status', 'paid');
if (error) { console.error(`Supabase: ${error.message}`); process.exit(2); }

const byPaymentId = new Map(orders.map((o) => [o.razorpay_payment_id, o]));
const problems = [];

for (const p of captured) {
  const order = byPaymentId.get(p.id);
  if (!order) {
    problems.push(`MONEY TAKEN, NO PAID ORDER: ${p.id} (₹${p.amount / 100})`);
    continue;
  }
  if (order.amount_paise !== p.amount) {
    problems.push(`AMOUNT MISMATCH ${order.number}: db ${order.amount_paise} vs rzp ${p.amount}`);
  }
  byPaymentId.delete(p.id);
}

for (const [paymentId, order] of byPaymentId) {
  problems.push(`ORDER PAID, NO CAPTURE: ${order.number} (${paymentId})`);
}

const capturedTotal = captured.reduce((s, p) => s + p.amount, 0);
console.log(`Reconciliation for ${day}`);
console.log(`  Razorpay captured : ${captured.length} payments, ₹${capturedTotal / 100}`);
console.log(`  Orders marked paid: ${orders.length}`);

if (problems.length === 0) {
  console.log('  ✓ Reconciled — no discrepancies.');
  process.exit(0);
}
console.error(`\n  ✗ ${problems.length} discrepancies:`);
for (const p of problems) console.error(`    - ${p}`);
process.exit(1);
```
